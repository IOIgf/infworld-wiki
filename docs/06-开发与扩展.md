# 开发与扩展

## 添加新的命途节点

**通过管理员后台**：
访问 `/admin/fate`，选择命途，点击"添加根节点"或某个节点旁的"添加子节点"，填写信息即可（自动校验深度不超过5层）。

**通过 SQL**（需注意序列同步）：
`INSERT INTO fate_node (fate_id, parent_id, name, description, required_level, cost_coins, in_battle, in_exploration, sort_order) VALUES (1, NULL, '新能力', '描述', 3, 100, true, false, 0);`
`SELECT setval('fate_node_id_seq', (SELECT max(id) FROM fate_node));`


## 添加新道具

**通过管理员后台**：
在 `/admin/items` 中填写名称、价格、效果（隐藏，AI 读取）、简短描述（AI 自动生成完整描述），选择分组。

**通过 SQL**：
直接插入 `item` 表，注意 `description` 字段需要手动编写或调用 AI 生成。


## 修改 AI 提示词

**单人副本**：
在 `app.py` 的 `dungeon_chat` 函数中，找到 `system_prompt` 字符串拼接处，修改副本规则、命途影响规则、战斗系统等部分。

**团队副本**：
在 `team_dungeon_chat` 函数中做类似修改。

提示词采用 f-string 拼接，变量包括 `dungeon.rules`、`fate_section`、`reward_hint` 等，修改时注意保持变量名不变。


## 扩展权限系统

**第一步**：在 `Permission` 表中插入新记录：
`INSERT INTO permission (key, name, description) VALUES ('new_perm', '新权限', '描述');`

**第二步**：在需要保护的路由上使用 `@permission_required('new_perm')` 装饰器。

**第三步**：在 `/admin/permissions` 界面即可为其他用户分配该权限（root 自动拥有）。


## 前端主题定制

颜色变量定义在 `style.css` 的 `body.light` 和 `body.dark` 块中，修改 `--accent`、`--bg-primary` 等即可调整主色调。

深色模式下的按钮使用暗金流光动画，位于 `body.dark button:not(...)` 规则中，可修改渐变颜色和动画参数。

所有模板继承自 `base.html`，全局导航和主题切换开关在此定义。


## 添加新页面（路由 + 模板）

**第一步**：在 `app.py` 中新增路由函数：
`@app.route('/new-page')`
`def new_page():`
`    return render_template('new_page.html', ...)`

**第二步**：在 `templates/` 目录下创建 `new_page.html`，继承 `base.html`，填充 `{% block content %}`。

**第三步**：若需新增静态资源（JS/CSS），放入 `static/` 目录，在模板中引用。


## 性能优化建议

- **数据库查询**：避免 N+1 查询，使用 `joinedload()` 或 `subqueryload()` 预加载关联数据。
- **缓存**：可使用 Redis 缓存命途树结构、排行榜等高频查询结果（需安装 Redis 并配置）。
- **静态资源**：使用 CDN 加速（如 KaTeX 已从 CDN 加载）。
- **日志**：生产环境关闭 SQLAlchemy 的 `echo` 选项。

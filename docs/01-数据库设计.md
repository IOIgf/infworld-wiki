# 数据库设计

**无限世界** 使用 PostgreSQL 作为生产数据库（开发时可使用 SQLite），共包含 31 张表。

## 核心表说明

### 用户与命途
- `user`：用户账号、积分、命途绑定（`fate_id`, `current_fate_node_id`）。
- `fate`：命途定义（名称、真言、颜色、图标）。
- `fate_node`：树形节点（`fate_id`, `parent_id`, `name`, `required_level`, `cost_coins`）。
- `user_fate_node`：玩家解锁的节点（`user_id`, `node_id`）。
- `fate_question`：25道测试题（含选项及权重 JSON）。
- `user_fate_answer`：玩家答题进度（答案数组、当前题目、是否提交）。

### 副本与团队
- `dungeon`：副本定义（名称、规则、是否隐藏、是否团队、最大人数、团队规则）。
- `dungeon_session`：单人副本会话（`history` JSON）。
- `team`：团队（`member_ids` JSON）。
- `team_session`：团队副本会话（`history` JSON）。
- `team_action`：团队公开行动记录。
- `team_chat`：团队聊天消息。
- `matching_queue`：团队匹配队列。
- `dungeon_clear_record`：首次通关记录。
- `dungeon_pool_item`：副本自定义奖池（数量范围、掉落概率）。

### 经济与道具
- `item`：道具定义（名称、价格、效果、描述、分组）。
- `item_group`：道具分组。
- `user_item`：玩家背包（`quantity`）。
- `order`：交易市场订单（`status`：active/sold/cancelled）。

### 社交与日志
- `chat_message`：世界聊天。
- `private_message`：私信（发送者/接收者）。
- `admin_log`：管理员操作日志（操作类型、目标、详情、IP）。
- `session_history_log`：副本历史存档（对话 JSON，`cleared` 标记）。
- `permission` / `user_permission`：权限系统（RBAC）。

### 其他辅助表
- `announcement`：系统公告。
- `fate_exp_log`：命途经验变更日志。
- 其余表用于记录临时状态、缓存等，详见代码模型定义。

---

## 主键与索引建议

为确保查询性能，已为以下字段创建索引：
- `fate_node.fate_id`、`fate_node.parent_id`
- `user_fate_node.user_id`、`user_fate_node.node_id`
- `dungeon_session.user_id`、`dungeon_session.dungeon_id`
- `user_item.user_id`、`user_item.item_id`
- `order.seller_id`、`order.status`
- `chat_message.timestamp`
- `private_message.sender_id`、`private_message.receiver_id`

所有外键均设置了级联策略（删除时自动处理关联数据）。

# 部署与运维

## 环境准备（Ubuntu 22.04）

安装系统依赖：
`sudo apt update`
`sudo apt install python3 python3-pip python3-venv postgresql postgresql-contrib nginx -y`

克隆项目（以 `inf_world` 为例）：
`cd /var/www`
`git clone <your-repo-url> inf_world`
`cd inf_world`

创建虚拟环境并激活：
`python3 -m venv venv`
`source venv/bin/activate`

安装 Python 依赖（需包含 `flask`, `sqlalchemy`, `psycopg2-binary`, `requests`, `mistune` 等）：
`pip install -r requirements.txt`


## 数据库迁移（SQLite → PostgreSQL）

**第一步**：创建 PostgreSQL 数据库和用户（以 `infworld` 数据库、`infuser` 用户为例）：
`sudo -u postgres psql`
`CREATE DATABASE infworld;`
`CREATE USER infuser WITH PASSWORD 'your_password';`
`GRANT ALL PRIVILEGES ON DATABASE infworld TO infuser;`
`\q`

**第二步**：运行迁移脚本（项目根目录下，虚拟环境激活）：
`python migrate_to_pg.py`

该脚本会逐表复制数据，自动处理外键和主键冲突。若遇主键冲突，需重置序列：
`SELECT setval('表名_id_seq', (SELECT max(id) FROM 表名));`

**第三步**：修改 `app.py` 中的数据库连接：
`app.config['SQLALCHEMY_DATABASE_URI'] = 'postgresql://infuser:your_password@localhost/infworld'`

**第四步**：重启应用。


## 进程管理（使用 PM2）

安装 PM2（需要 Node.js）：
`npm install -g pm2`

启动 Gunicorn（4 个 worker，监听 5000 端口）：
`pm2 start gunicorn --name infworld -- -w 4 -b 0.0.0.0:5000 app:app`

保存进程列表，设置开机自启：
`pm2 save`
`pm2 startup`


## 备份与恢复

**备份**（建议每日 cron）：
`pg_dump -U infuser -h localhost infworld > /var/backups/infworld_$(date +%Y%m%d).sql`

**恢复**：
`psql -U infuser -h localhost infworld < /var/backups/infworld_20260101.sql`


## 常用维护命令

- 查看应用日志：`pm2 logs infworld` 或 `journalctl -u infworld`
- 重启应用：`pm2 restart infworld` 或 `systemctl restart infworld`
- 进入 Flask Shell 调试：`flask shell`
- 手动执行数据库清理：已内置定时任务，每天自动执行
